01 · Register

One door, three ways in

Register

Welcome and sign-in on one screen. The partner's brand moment and the door into the app share it.

  • Apple, Google or email sign-in
  • Account is matched to the application by email
  • Match found → Onboarding. No match → Not selected

States · default · signing in · no network

Email code

Only for email sign-in. Six digits, auto-fill from the mail app.

  • Resend after 30 s
  • Wrong code shows inline, never clears what was typed

States · typing · wrong code · expired · verified

Invite code

Fallback when the sign-in email doesn't match an application. Becomes a link from Register, not its own step.

  • One code per selected athlete, sent with the selection message
  • Code links this account to the application

States · invalid · already used · success

Not selected

What every applicant outside the squad sees if they download the app.

  • Kind, short, no dead end
  • Links to other peakst8 events

03 · Today

The daily loop

Home

Programme hero, today's goals, what's coming up. Tracker status sits in the header so a dropped sync is seen.

  • Goals tick themselves when the activity syncs
  • Tracker chips open Connections (Journey 05)
  • Tabs: Home, Programme, Discover, Progress

States · first visit (no goals yet) · goal open · partial · all done · rest day

Goal detail

The workout behind a goal: warm-up, main set, stretches.

  • Steps with durations, stretch video
  • Manual entry link when a run didn't sync
Goal complete + daily card

One moment, not two: the goal is done and the card is ready. The goal-complete notification opens here.

  • Distance, time, pace, zone from the synced activity
  • Add a photo or video, three layouts

States · generating · ready · failed (goal still counts) · shared

Sunday report

The week in one card. The Sunday notification opens here.

  • Goals done, breakdown by type, rank and movement
  • One line from the coach
Discover

Every programme event in one list: group runs, benchmarks, clinics. New-event notifications open the event.

  • Upcoming / Past, filter by city
  • Event detail: when, where, RSVP
Progress

The day-by-day record. Week strip, done vs planned, other activities, readiness.

  • Tap a day to see it
  • Rest day shows “Rest is part of the plan”

04 · Coach

Talk to your coach, book the weekly call

Your performance team

Three people, one tap away. The weekly 1:1 lives on the head coach's card.

  • Profile, chat with unread count
  • 1:1 row: pending · scheduled · complete
Chat

One-to-one messages. A goal can be attached so the coach sees what the athlete means. Coach-message notifications open here.

  • Attach today's goal as context
  • Sent / read state, reply-time promise in the header
Book your 1:1

Pick a day and a time; the call lands in the athlete's calendar with a Meet link.

  • Coach's open slots only, one call per programme week
  • Calendar is optional: a toggle, not a gate
Booked / complete

Confirms the booking; after the call the same sheet says “1 of 1 done, next call opens next week”.

  • Reschedule until 2 hours before

05 · Integrations

One list, every tracker

Connect your watch

One list of every supported tracker. The athlete connects what they own.

  • Strava for most watches, Garmin direct, Ultrahuman for sleep and recovery
  • At least one activity source to continue, or “I don't have a watch”
  • Partners choose which trackers count for their cohort
Connected

Proves it worked by showing a real synced run, not just a tick.

  • Last synced activity and its source watch
  • Same screen for each provider
Connections

Opens from the tracker chips on Home, or from a reconnect push when a token expires.

  • Says how long it's been broken and what it costs
  • Reconnect is the main action; disconnect is a quiet link with a confirm step
Add a run by hand

For athletes without a watch and for failed syncs, with screenshot proof.

  • Distance, time, date, screenshot
  • Counts once the coach approves
