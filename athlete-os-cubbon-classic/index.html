Technical spec

The full list of what engineering must have ready before we onboard Cubbon's runners is in the technical spec. The main constraint is getting runs in.

Scale and migration come first. The spec also covers two things that apply to the whole platform. Strava at scale (section 6): webhooks only, a shared rate budget, our own activity store, Apple Health and Health Connect as the default, and leaderboards that show points rather than Strava data. Yoska migration (section 7): inventory, data foundation, engine, then segments one at a time (races, clubs, corporates with Puma first, brands, then a decision on coaches), each with a dual run and a rollback.

How it works

  1. Settings. The organiser turns Embed on for the event: allowed websites, colour, button label, GA4 and pixel ids, bulk minimum and discount.
  2. Loader. The race site includes <div data-peakst8-event="…"> and /embed/v1.js. The loader calls GET /embed/v1/events/:eventId (CORS limited to the event's websites, cached 60 s) and renders passes with the current price.
  3. Checkout. Register opens the existing peakst8 event page in embed mode inside an overlay (?embed=1&register=1): details, email OTP, Razorpay, ticket. On success the page posts purchase to the race site, and the loader fires GA4 and the pixel.
  4. Pricing. registrationService.register asks embedService.priceForRegistration for the active early-bird tier, compares it with any coupon, and charges the cheaper. The tier is saved on the registration for sales-by-tier reports.
  5. Bulk. A group code is an existing coupon with one use per entry bought, at the bulk discount.
  6. Import. The organiser previews a KonfHub CSV, then imports it. Each row becomes a peakst8 registration with a real ticket (QR code and image) in the background.

Rules

  • No stacking. A runner gets the bigger of the early-bird tier and their coupon or group code. A 20% bulk code beats the 15% tier.
  • Tiers apply in order while they're open and have seats. Paid and pending registrations hold a tier seat. Tiers apply on ps8.club too, so prices match everywhere.
  • Imports never send emails. The "your entry has moved" email goes out separately once the counts are checked.
