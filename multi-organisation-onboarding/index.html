peakst8 Multi-Organisation Onboarding

Any club's training programme, in the peakst8 app.

The peakst8 app used to run one training programme, PUMA Project 3. Now any club can run its own. Athletes join with an invite, follow the plan week by week, and see only their own programme's coaches, challenges and leaderboard.

1. What it is

A training programme now belongs to a club, and the app shows each athlete the programme they were invited to. It is a feature of its own, like Passport. Cubbon Classic 10K is the first customer, not the reason it exists.

OrganisationA club on peakst8

A race, a run club or a brand's training squad.

ProgrammeIts training plan

Start and end dates, coaches and athletes. A club can run more than one.

InviteThe way in

A link and a six-character code, emailed to one athlete, for one programme.

The appSame app, their programme

Home, training, leaderboard, challenges and coach chat, all for that programme only.

Everything athletes had in Project 3 works the same way for every programme: the training week, Strava sync, the leaderboard, weekly challenges, coach chat and broadcasts, and booked sessions with a meeting link. Puma itself now runs on the same flow.

3. How an athlete joins

One email, one tap, a short sign-up. An athlete who already has a programme skips all of it and lands on Home.

1 · InviteAn email arrives

"You're invited to train with peakst8", with a link and a six-character code.

2 · OpenLink or code

The link opens the app. If it doesn't, the athlete types the code in the app.

3 · Sign inEmail code, Google or Apple

New athletes add their name, birthday and sports.

4 · Set upNotifications and photo

Then connect Strava so runs sync on their own.

5 · TrainHome

This week's workouts, for their programme only.

If the athlete closes the app halfway, it reopens on the step they stopped at. The invite page also offers the App Store and Google Play for athletes who do not have the app yet.

5. How it's built

The athlete's programme is worked out by peakst8 from who is signed in. The app never tells the server which programme, club or event to show.

  • One active programme per athlete. A training programme hangs off a ticket of an Experience, which belongs to a club. That chain is how peakst8 knows the organisation.
  • An invite code points at one programme. Using it puts the signed-in athlete in that programme and marks the code used.
  • Every screen asks "what is my programme?" first, then loads training, leaderboard, coaches and challenges for it.
  • Training plans, scoring and chat still come from the partner training system (Yoska), reached through peakst8 with the athlete's own access.

The data model, routes, caching rules and the release checklist are in the technical spec. It was written on 11 Nov 2026, before go-live, so its delivery-status table is older than this page.

6. Rules

  • One invite, one athlete. Once used, nobody else can use it. The athlete who used it can enter it again safely.
  • One programme at a time. An athlete cannot be active in two programmes.
  • Programmes are kept apart, including two in the same club: separate athletes, separate leaderboards.
  • Wrong or used code: the same message, "Invalid invite code", so nothing is revealed about the code.
  • No programme, no training screens. An athlete without a programme is taken to the invite screen.

8. Journeys and done criteria

  1. As a new athlete, I open my invite and start training. Done when: the link opens the join screen, I sign up, and Home shows my programme's week.
  2. As an athlete without the app, I get in anyway. Done when: the invite page shows my code and the store buttons, and typing the code in the app works.
  3. As a Project 3 athlete, nothing changes for me. Done when: I open the app and land on Home without being asked for a code.
  4. As an athlete in one programme, I never see another. Done when: two programmes in one club show different leaderboards and coaches.
  5. As a club, my programme starts without an app release. Done when: the team sets up the programme and sends invites the same day.
